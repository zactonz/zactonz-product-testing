## Auth boundaries

- **Public, no token:** S1 `/health`, S2 `/app`, S3 `/search`, S6 `/preview`, S10–S12.
- **Token required:** S4, S5, S7, S8, S9. Token → user id via the `TOKENS` dict
  (`app.py:5`); `who()` at `app.py:52` strips `"Bearer "` by **substring replace**,
  not prefix match.
- **Privilege column that exists but has no surface:** `users.is_admin`
  (`app.py:9`). Nothing in the route table reads it for an authorization decision
  and nothing documents it as settable — it is returned by S9's response body
  (`app.py:148-149`).

## Non-HTTP surfaces

- **Scheduled jobs / queue consumers / webhook receivers:** none. `POST /jobs`
